RINGKASAN PERUBAHAN PROYEK KATALOG WEB
=======================================

Proyek  : Katalog Teknik / Mandiri Perkakas
Branch  : katalog-web
Tanggal : 24 Juli 2026

Dokumen ini merangkum kondisi akhir perubahan yang dikerjakan sejak awal
pembahasan. Keputusan atau implementasi sementara yang kemudian diralat tidak
dicatat sebagai fitur aktif, kecuali diperlukan untuk menjelaskan kondisi akhir.


1. HALAMAN DETAIL PRODUK
------------------------

- Menambahkan halaman detail produk dengan route:
  /products/[slug]

- Card produk pada katalog dan beranda sekarang mengarahkan pengunjung ke
  halaman detail produk, bukan hanya membuka modal.

- Slug produk dibentuk dari nama dan identitas produk agar URL mudah dibaca.

- Halaman detail produk berisi:
  - Breadcrumb.
  - Galeri hingga empat foto produk.
  - Nama dan kategori produk.
  - Harga normal atau harga diskon.
  - Persentase diskon.
  - Rating yang dapat ditampilkan atau disembunyikan.
  - Jumlah produk terjual.
  - SKU/kode produk bila tersedia.
  - Informasi ketersediaan dan jaminan produk.
  - Tombol Minta Penawaran.
  - Tombol Tanya via WhatsApp.
  - Deskripsi produk.
  - Spesifikasi produk.
  - Bagian Produk Terkait.

- Produk terkait diprioritaskan berdasarkan:
  1. Subkategori yang sama.
  2. Kategori kedua yang sama.
  3. Kategori utama yang sama.
  4. Jumlah terjual.

- Produk yang sedang dibuka tidak dimasukkan ke Produk Terkait.

- Klik card Produk Terkait membuka halaman detail produk tersebut.

- Panel informasi di sisi kanan halaman detail dirapikan agar batas bawahnya
  sejajar dengan foto utama pada desktop.

- Tata letak halaman detail tetap responsif dan berubah menjadi susunan vertikal
  pada tablet/mobile.


2. KOMPONEN PRODUCT CARD
------------------------

- Membuat komponen ProductCard terpisah dan dapat digunakan ulang.

- ProductCard digunakan pada:
  - Halaman katalog produk.
  - Bagian produk unggulan/terlaris di beranda.
  - Bagian Produk Terkait.

- Isi dan identitas visual card katalog lama tetap dipertahankan.

- Card dibuat lebih pendek dan padat:
  - Ukuran gambar disesuaikan.
  - Ukuran tulisan diperkecil secara proporsional.
  - Tombol Penawaran dipadatkan.
  - Jarak internal card dikurangi.

- Tombol Penawaran pada semua card dalam satu baris sudah disejajarkan, termasuk
  antara produk yang memiliki label "Garansi Harga Terbaik" dan yang tidak.

- Card desktop pada halaman katalog disesuaikan agar mendekati proporsi card di
  situs referensi smtindo.com.

- Card beranda menggunakan ukuran yang sama dengan card halaman produk.

- Grid produk beranda pada desktop menggunakan lima card per baris agar ruang
  kiri dan kanan lebih terisi.

- Grid mobile menggunakan susunan dua kolom yang tetap ringkas dan terbaca.


3. HALAMAN KATALOG PRODUK
-------------------------

- Menambahkan tata letak pencarian dan filter responsif yang terinspirasi dari
  alur smtindo.com tanpa menyalin desain secara identik.

- Filter mobile mencakup:
  - Pencarian produk/SKU.
  - Kategori.
  - Merek.
  - Rentang harga.
  - Urutan produk terbaru.

- Filter harga memiliki:
  - Input harga minimum.
  - Input harga maksimum.
  - Tombol Terapkan.
  - Chip filter aktif untuk minimum dan maksimum.
  - Tombol X untuk menghapus nilai tertentu.
  - Tombol Reset Filter.
  - Efek hover pada kontrol harga dan reset.

- Input harga otomatis menggunakan pemisah ribuan Indonesia, misalnya:
  1.000, 10.000, 1.000.000.

- Sidebar desktop ditambahkan:
  - Navigasi kategori tiga tingkat.
  - Filter merek.
  - Filter rentang harga.
  - Jumlah produk pada kategori/merek.
  - Tombol penerapan harga.

- Ukuran judul "Jelajahi Kategori" diperkecil agar lebih proporsional.

- Toolbar, pencarian, filter aktif, dan grid produk dipadatkan.


4. PROMO PRODUK
---------------

- Promo tidak lagi menggunakan upload gambar banner terpisah.

- Promo ditentukan langsung dari produk yang sudah ada.

- Pada Admin -> Manajemen Produk tersedia checkbox/status Promo.

- Opsi promo juga tersedia pada formulir tambah/edit produk.

- Produk yang ditandai promo otomatis tampil di hero halaman produk menggunakan:
  - Foto utama produk.
  - Nama produk.
  - Kategori.
  - Harga.
  - Harga diskon dan persentase diskon bila ada.
  - Rating bila diaktifkan.
  - Jumlah terjual.
  - Status terlaris.
  - Link menuju detail produk.

- Jika lebih dari satu produk dipilih sebagai promo:
  - Slider berganti otomatis.
  - Tersedia tombol sebelumnya/berikutnya.
  - Tersedia indikator slide.
  - Mendukung swipe pada perangkat sentuh.
  - Autoplay berhenti sementara saat hover atau fokus.
  - Preferensi reduced motion dihormati.

- Jika tidak ada produk promo, hero kembali ke tampilan normal.

- Desain card promo terakhir menggunakan konsep single-surface:
  - Tidak ada panel yang saling menumpuk.
  - Foto dan informasi tersusun vertikal normal.
  - Bentuk luar memiliki sudut asimetris.
  - Area foto memiliki lengkungan asimetris.
  - Informasi menyatu dengan permukaan utama.
  - Pemisah menggunakan garis gradient tipis.
  - Nomor slide ditampilkan di sudut card.
  - Hover hanya memberi gerakan halus pada area foto.
  - Desain mobile mengikuti konsep yang sama.


5. MARKETPLACE PER PRODUK
-------------------------

- Menambahkan dua URL opsional pada setiap produk:
  - URL produk Tokopedia.
  - URL produk TikTok Shop.

- Field URL tersedia pada formulir tambah/edit produk di dashboard admin.

- URL harus berupa alamat web lengkap dengan http:// atau https://.

- Pada halaman detail produk tampil panel "Tersedia di Marketplace".

- Prioritas link tombol marketplace:
  1. Gunakan URL marketplace khusus produk jika diisi.
  2. Jika kosong, gunakan link toko global dari pengaturan footer.
  3. Jika keduanya kosong, tombol marketplace tidak ditampilkan.

- Label tombol menyesuaikan tujuan:
  - "Beli di Tokopedia/TikTok Shop" untuk link produk langsung.
  - "Kunjungi Tokopedia/TikTok Shop" untuk link toko global.

- Tombol marketplace membuka tab baru.

- Desain panel menggunakan aksen hijau, cyan, dan fuchsia secara halus.

- Tombol Penawaran dan WhatsApp tetap tersedia sebagai alternatif.


6. TEMA DAN TAMPILAN BERANDA
----------------------------

- Tema awal situs diubah menjadi mode terang.

- Pengguna tetap dapat berpindah ke mode gelap melalui kontrol tema.

- Warna tulisan hero mode terang diperbaiki agar lebih terbaca tanpa menutupi
  gambar latar dengan overlay yang terlalu kuat.

- Warna teks sekunder, tombol, dan proof item pada hero disesuaikan.

- Card "Mengapa Memilih Kami" dipadatkan:
  - Tinggi minimum dikurangi.
  - Padding diperkecil.
  - Jarak ikon, judul, dan deskripsi dirapatkan.

- Card "Alur Kerja" dipadatkan:
  - Padding dikurangi.
  - Jarak antar elemen diperkecil.
  - Tinggi card tidak lagi terlalu jangkung.

- Jarak antara section berikut telah dirapatkan:
  - Mengapa Memilih Kami ke Produk Unggulan.
  - Produk Unggulan ke Alur Kerja.
  - Alur Kerja ke section berikutnya.
  - Section terakhir ke footer.

- Jarak card produk dengan panel kategori Produk Terlaris sudah diperbaiki.


7. JARAK VERTIKAL ANTAR-HALAMAN
-------------------------------

- Ritme jarak section diseragamkan dengan beranda.

- Jarak umum desktop menjadi sekitar 44 px.

- Jarak umum mobile menjadi sekitar 32 px.

- Padding bawah PageHero diperkecil.

- Masalah padding ganda pada section pertama dengan class pt-0 diperbaiki.

- Penyesuaian berlaku terutama pada:
  - Halaman Layanan.
  - Halaman Tentang.
  - Halaman Kontak.
  - Section umum lainnya.

- Halaman Produk dan Galeri tetap mempertahankan aturan layout khususnya.


8. DASHBOARD ADMIN - PRODUK
---------------------------

- Menambahkan pengaturan tampil/sembunyikan rating per produk.

- Jika rating dinonaktifkan:
  - Bintang dan angka rating tidak muncul pada card.
  - Rating tidak muncul pada halaman detail.
  - Data rating tetap tersimpan.

- Menambahkan checkbox pemilihan produk pada tabel admin.

- Menambahkan checkbox "pilih semua produk yang sedang tampil".

- Menambahkan status jumlah produk yang dipilih.

- Menambahkan tombol Hapus Terpilih untuk menghapus beberapa produk sekaligus.

- Penghapusan massal:
  - Meminta konfirmasi.
  - Menampilkan status proses.
  - Melaporkan jumlah berhasil/gagal.
  - Menghapus pilihan yang berhasil diproses.

- Menambahkan checkbox Promo langsung pada tabel produk.

- Status promo dapat diperbarui tanpa membuka halaman edit.

- Form tambah/edit produk telah diperluas untuk:
  - Rating tampil/sembunyi.
  - Produk terlaris.
  - Produk promo.
  - URL Tokopedia per produk.
  - URL TikTok Shop per produk.


9. MEDIA SOSIAL DAN FOOTER
--------------------------

- Menambahkan kanal global:
  - Tokopedia.
  - TikTok Shop.

- Link dapat dikelola melalui Admin -> Sosial Media.

- Ikon hanya ditampilkan di footer jika URL terkait sudah diisi.

- Ikon Tokopedia dan TikTok Shop dibuat berbeda dari ikon TikTok biasa.

- Statistik dashboard sosial media diperbarui dari empat menjadi enam kanal.

- Label Tokopedia dan TikTok Shop juga tersedia pada halaman pengaturan umum.

- Link toko global juga berfungsi sebagai fallback tombol marketplace pada
  halaman detail produk.


10. OPTIMASI GAMBAR CLOUDINARY
------------------------------

- Menambahkan helper optimasi URL Cloudinary.

- Gambar Cloudinary menggunakan transformasi otomatis:
  - f_auto untuk memilih WebP/AVIF sesuai dukungan browser.
  - q_auto untuk kualitas/kompresi otomatis.

- Ukuran gambar disesuaikan berdasarkan konteks pemakaian.

- Optimasi diterapkan pada:
  - Card produk.
  - Galeri detail produk.
  - Promo produk.
  - Galeri situs.
  - Logo partner bila relevan.

- Upload gambar produk tetap mendukung crop persegi dan maksimal empat foto.

13. PERUBAHAN DATABASE
----------------------

  Mengatur apakah rating produk ditampilkan.

- products.is_promotion
  Menentukan apakah produk tampil pada card promo.

- products.tokopedia_url
  URL Tokopedia khusus produk, bersifat opsional.

- products.tiktok_shop_url
  URL TikTok Shop khusus produk, bersifat opsional.

- settings.link_tokopedia
  Link toko Tokopedia global.

- settings.link_tiktok_shop

- database/ensure-product-promotions-table.sql
- database/ensure-product-marketplace-links.sql
